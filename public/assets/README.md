# Wiraqocha V1 assets

This directory contains the V1 production-style individual assets used by the PixiJS board renderer.

## Individual assets

- `terrain/` — jungle, ruins, mountain, Somnium, Machine Cemetery, caves
- `pawns/` — Base Camp, Explorer, Drilling, Zeppelin, Android Explorer, Juggernaut, Mechanical Miner
- `tokens/` — four Artifacts, Force Field, Flying Fortress, Death Ray, Machine Cemetery token, Devastated token
- `resources/` — resource cube stack and Somnium crystal

The PNGs are extracted/cropped from the V1 art reference sheet and normalized for direct PixiJS loading. The original concept sheets remain under `concept/` as art-direction references.

These are prototype production assets, not a replacement for separately commissioned/licensed final artwork if the game is distributed publicly.
